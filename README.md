## CodeQuack – Gamified Programming Learning Platform
CodeQuack is a beginner-friendly programming learning platform designed to make learning (C++ and Python) interactive, simple, and engaging.
## Features
1.	User registration and authentication
2.	Beginner-friendly C++ and Python lessons
3.	Interactive quizzes with instant feedback
4.	Progress tracking
5.	XP, levels, badges, and daily streaks
6.	Programming learning games
7.	AI-assisted programming Q&A
8.	Chat rooms
9.	Feedback system
10.	Course completion certificates
11.	Responsive user interface
## Technologies
1.	HTML5 / CSS3
2.	Tailwind CSS
3.	JavaScript (Vanilla JS)
4.	Laravel 12+
5.	Firebase Authentication
6.	Firebase Firestore & Storage
7.	Groq API
8.	Laravel DOMPDF
## Installation
git clone YOUR_GITHUB_REPOSITORY_LINK
cd CodeQuack
composer install
npm install
copy .env.example .env
php artisan key:generate
Configure your Firebase and API credentials in the `.env` file.
## Run the Project
Start Laravel:
php artisan serve
In another terminal, start Vite:
npm run dev
Then open the local URL provided by Laravel, usually: http://127.0.0.1:8000
